# Electrical Service Reference

## Purpose

This document provides reference information for classifying electrical requests and identifying common electrical service requirements.

This file is **read-only**. Agents must not modify it.

---

## Service Category

Primary category:

**Electrical**

## Common Electrical Issues

| Issue                        | Description                                  | Typical Service         |
| ---------------------------- | -------------------------------------------- | ----------------------- |
| Power outage in part of home | Some areas have no power while others do     | Electrical diagnosis    |
| Circuit breaker issue        | Breaker trips or does not remain on          | Electrical diagnosis    |
| Outlet not working           | Electrical outlet does not provide power     | Outlet repair           |
| Light fixture issue          | Light fixture does not operate correctly     | Lighting repair         |
| Switch issue                 | Electrical switch does not operate correctly | Switch repair           |
| Flickering lights            | Lights repeatedly flicker or dim             | Electrical diagnosis    |
| New outlet installation      | Customer wants an additional outlet          | Electrical installation |
| Ceiling fan issue            | Fan does not operate correctly               | Electrical/fan service  |
| Electrical inspection        | Customer requests electrical inspection      | Electrical inspection   |

## Urgency Guidelines

### Potentially urgent

Treat the following as potentially urgent:

* smoke from electrical equipment
* burning electrical smell
* visible sparks
* exposed electrical wiring
* repeated electrical arcing
* conditions indicating an immediate electrical hazard

The system should not attempt to provide detailed electrical repair instructions.

When a potentially dangerous condition is reported, prioritize professional evaluation.

### Normal

Examples:

* non-working outlet
* faulty light switch
* flickering light
* ceiling fan issue
* electrical inspection

## Required Information for Provider Search

A provider search normally requires:

* problem description
* service category
* service location
* preferred appointment date
* preferred appointment time

Optional information may include:

* affected room
* number of affected outlets/lights
* whether breakers are involved
* whether the problem affects part or all of the property

Do not invent missing information.

## Classification Rules

* Use Electrical when the primary issue concerns electrical wiring, outlets, switches, lighting, circuits, or electrical equipment.
* Do not provide detailed instructions for repairing potentially dangerous electrical conditions.
* Do not diagnose a specific electrical fault unless supported by the customer's description.
* If the classification is uncertain, request clarification.
