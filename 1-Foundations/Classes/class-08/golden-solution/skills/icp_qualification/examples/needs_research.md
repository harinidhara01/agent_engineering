# Example: NEEDS_RESEARCH

**Account:** Meridian Industrial Group — industrial_automation, employee count unknown (privately held, headcount not published), Europe. Source note: "The company recently discussed modernization initiatives."

**Outcome:** NEEDS_RESEARCH

**Rationale:** Industry and region are both plausible fits. Employee count is unknown, and the minimum-employee-count criterion cannot be evaluated without it — this is not the same condition as failing the criterion, and must not be treated as a disqualification. The "modernization initiatives" note is too vague on its own to count as a decisive pain signal; it does not name a specific system, process, or gap the way the qualifying example's paper-checklist note does.

This example illustrates: the difference between "unknown" and "false" for a missing decisive fact, and the difference between a vague signal and a concrete one.
